# Registro do ETL — coorte SIH/SUS Minas Gerais

Recorte territorial consolidado em 19/09/2026: os 89 municípios do Norte de Minas, via API de localidades do IBGE
(acesso nesta data; a fonte consta das referências do projeto).

A base 2019-2025 não foi rebaixada nesta data: ela veio, no início de setembro, do ETL inicial — anterior à primeira
versão deste repositório. O log daquela passada, guardado na máquina do autor, não carrega data nem hash por
competência; o ETL aqui versionado grava `source`, `sha256` e `downloaded_at` por competência baixada. Limitação
registrada: as linhas de 2019-2025 desse log pertencem a código não versionado.

As competências de 2026 serão baixadas pelo ETL versionado depois de o código estar congelado no pré-registro.
